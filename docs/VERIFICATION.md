- `dotnet test tests/Sweetch.Tests -c Release`: 73 пройдено, 0 ошибок.

- Проверены построение окон в русском/английском интерфейсе и светлой/тёмной темах, реальные конвертации изображений, PDF, таблиц, субтитров и архивов.

- Проверены OCR, наблюдаемая папка, виртуальные вложения, изображения и ссылки при перетаскивании, сохранение настроек.

- Официальный ZIP Pandoc 3.12.1 проверен по SHA-256 сценарием сборки.

Результаты повторной проверки GitHub Actions доступны на вкладке Actions. Для каждого опубликованного ZIP прилагается файл `.sha256`.
