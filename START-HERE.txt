Sweetch Desktop 1.0.0 — Windows x64

1. Распакуйте ВЕСЬ архив в отдельную папку.
2. Запустите SweetchDesktop.exe.
3. Нажмите «Выбрать файлы» или перетащите файлы в окно.
4. Нажмите «Выбрать формат» и выберите действие в круговом меню.

Результат сохраняется отдельно. Исходный файл не перезаписывается.
Если закрыть окно, программа остаётся рядом с часами в трее.
Для полного завершения: правая кнопка по значку → «Выход».

Shift при перетаскивании: конвертация. Ctrl: инструменты. Alt: действия.
Ctrl + Alt + Space: меню для выбранных в Проводнике файлов.
Автозапуск и контекстное меню включаются в настройках по желанию.

Pandoc и .NET включены. FFmpeg скачивается в настройках для аудио/видео.
LibreOffice нужен отдельно для части операций Office/PDF.
Windows 10 1809+ / Windows 11, x64.
